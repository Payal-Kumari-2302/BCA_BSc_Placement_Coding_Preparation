# 🔥 Priority 1 – Must Practice First

### Q1. Bubble Sort

**File:** `01_Bubble_Sort.py`

**Problem:** Sort an array in ascending order by repeatedly comparing adjacent elements and swapping them if they are in the wrong order.

**Example**
```text
Input: [5, 3, 8, 4, 2]
Output: [2, 3, 4, 5, 8]
```
- [ ] Completed

### Q2. Selection Sort

**File:** `02_Selection_Sort.py`

**Problem:** Sort an array by repeatedly finding the smallest element from the unsorted portion and placing it at the correct position.

**Example**
```text
Input: [64, 25, 12, 22, 11]
Output: [11, 12, 22, 25, 64]
```
- [ ] Completed

### Q3. Insertion Sort

**File:** `03_Insertion_Sort.py`

**Problem:** Sort an array by taking one element at a time and inserting it into its correct position in the sorted portion.

**Example**
```text
Input: [12, 11, 13, 5, 6]
Output: [5, 6, 11, 12, 13]
```
- [ ] Completed

# ⭐ Priority 2 – Important Practice

### Q4. Merge Sort

**File:** `04_Merge_Sort.py`

**Problem:** Sort an array using the divide-and-conquer approach by dividing it into smaller parts and merging the sorted parts.

**Example**
```text
Input: [38, 27, 43, 3, 9, 82, 10]
Output: [3, 9, 10, 27, 38, 43, 82]
```
- [ ] Completed

### Q5. Quick Sort

**File:** `05_Quick_Sort.py`

**Problem:** Sort an array by selecting a pivot element and partitioning the remaining elements around it.

**Example**
```text
Input: [10, 7, 8, 9, 1, 5]
Output: [1, 5, 7, 8, 9, 10]
```
- [ ] Completed

# 📌 Priority 3 – Additional Practice

### Q6. Heap Sort

**File:** `06_Heap_Sort.py`

**Example**

Input: [12, 11, 13, 5, 6, 7]

## 📊 Sorting Algorithm Complexity

| Algorithm | Best Case | Average Case | Worst Case |
|---|---:|---:|---:|
| Bubble Sort | O(n) | O(n²) | O(n²) |
| Selection Sort | O(n²) | O(n²) | O(n²) |
| Insertion Sort | O(n) | O(n²) | O(n²) |
| Merge Sort | O(n log n) | O(n log n) | O(n log n) |
| Quick Sort | O(n log n) | O(n log n) | O(n²) |
| Heap Sort | O(n log n) | O(n log n) | O(n log n) |

*Note: Bubble Sort and Insertion Sort best-case complexities assume optimized implementations.*
