# 🔥 Priority 1 – Must Practice First

### Q1. Linear Search

**File:** `01_Linear_Search.py`

**Problem:** Search for a target element in an array by checking each element one by one. Return its index if found; otherwise, indicate that the element is not present.

**Example**
```text
Input:
Array: [10, 20, 30, 40, 50]
Target: 30

Output: Element found at index 2
```
- [ ] Completed

### Q2. Binary Search

**File:** `02_Binary_Search.py`

**Problem:** Search for a target element in a sorted array by repeatedly dividing the search range into two halves.

**Example**
```text
Input:
Array: [10, 20, 30, 40, 50]
Target: 40

Output: Element found at index 3
```
- [ ] Completed

# ⭐ Priority 2 – Important Practice

### Q3. Detect Loop in a Linked List

**File:** `03_Detect_Loop_In_Linked_List.py`

**Problem:** Determine whether a singly linked list contains a cycle or loop.

**Example**
```text
Input: 10 → 20 → 30 → 40 → 50
                    ↑         |
                    └─────────┘

Output: Loop Detected
```
- [ ] Completed

### Q4. Find the Middle of a Linked List

**File:** `04_Find_Middle_Of_Linked_List.py`

**Problem:** Find the middle node of a singly linked list. If the list has an even number of nodes, return the second middle node.

**Example**
```text
Input: 10 → 20 → 30 → 40 → 50

Output: 30
```
- [ ] Completed

### Q5. Reverse a Linked List

**File:** `05_Reverse_Linked_List.py`

**Problem:** Reverse the direction of links in a singly linked list so that the last node becomes the first node.

**Example**
```text
Input: 10 → 20 → 30 → 40

Output: 40 → 30 → 20 → 10
```
- [ ] Completed
